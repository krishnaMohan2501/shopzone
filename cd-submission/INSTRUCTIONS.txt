=================================================
  OPTION A: Run with Docker (EASIEST — Recommended)
=================================================

REQUIREMENT: Docker Desktop installed
  Download: https://www.docker.com/products/docker-desktop/

STEPS:
  1. Install Docker Desktop and start it
  2. Open terminal / command prompt in THIS folder
  3. Run:
       Windows:    docker-run.bat
       Linux/Mac:  bash docker-run.sh
  4. Wait ~3 minutes for first-time build
  5. Open browser: http://localhost:8080

That's it. No Java, no PostgreSQL installation needed.

=================================================
  OPTION B: Run with JAR (needs Java 17 + PostgreSQL)
=================================================

REQUIREMENTS:
  - Java 17+  -> https://adoptium.net/
  - PostgreSQL 15+ -> https://www.postgresql.org/download/

STEPS:
  1. Start PostgreSQL and create the database:
       psql -U postgres -f setup.sql
  2. Start the application:
       Windows:    run.bat
       Linux/Mac:  bash run.sh
  3. Open browser: http://localhost:8080

=================================================
  FEATURES
=================================================

  - User registration and login (JWT authentication)
  - Product catalog with search and category filter
  - Shopping cart with quantity management
  - Checkout and order placement
  - Order history for customers
  - Admin panel: manage products (CRUD) and order statuses

=================================================
  TECH STACK
=================================================

  Backend:  Java 17, Spring Boot 3.2, Spring Security 6, Spring Data JPA
  Database: PostgreSQL 15
  Frontend: React 18, Vite, Tailwind CSS, React Router 6
  Auth:     JWT (jjwt 0.12)
  Build:    Maven 3 (single executable JAR, frontend bundled inside)
  Docker:   Multi-stage build, docker compose
